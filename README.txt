ARAIOEI SMART TRY-ON MIRROR — เว็บไซต์ต้นแบบ

วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. เปิดไฟล์ index.html ด้วย Chrome, Edge, Firefox หรือ Safari
3. เว็บไซต์เป็น Static HTML/CSS/JavaScript ไม่ต้องติดตั้งโปรแกรมหรือรันเซิร์ฟเวอร์เพื่อชมหน้าเว็บ

สิ่งที่ทำงานได้ในต้นแบบ
- Responsive สำหรับคอมพิวเตอร์ แท็บเล็ต และมือถือ
- เมนูนำทางและปุ่มเลื่อนไปยังส่วนต่าง ๆ
- Demo เลือกสไตล์ Casual / Office / Travel / Party พร้อมเปลี่ยนภาพและคำอธิบาย
- ตรวจสอบช่องจำเป็นและรูปแบบอีเมลในฟอร์ม พร้อมแจ้งสถานะการจำลองส่งข้อมูล
- หน้าต่างนโยบายความเป็นส่วนตัวสำหรับต้นแบบ

ข้อจำกัดที่ควรทราบ
- ฟอร์มยังไม่ส่งข้อมูลไปยังเซิร์ฟเวอร์ เพราะยังไม่มี Backend
- ไม่มีการเปิดกล้อง ตรวจจับรูปร่าง หรือประมวลผล Virtual Try-On / AI แบบเรียลไทม์
- ภาพและคำอธิบายเป็นภาพแนวคิดสำหรับการนำเสนอผลิตภัณฑ์ ไม่ใช่การยืนยันสเปกที่ยังไม่ได้ตรวจสอบ
- อีเมลและเบอร์โทรศัพท์ธุรกิจไม่ได้ถูกใส่ไว้ เนื่องจากยังไม่มีข้อมูลที่ยืนยัน
- ฟอนต์จาก Google Fonts จะโหลดเมื่อเชื่อมต่ออินเทอร์เน็ต หากออฟไลน์จะใช้ฟอนต์สำรองในเครื่อง

ก่อนเผยแพร่จริง ควรใส่ช่องทางติดต่อที่ยืนยันแล้ว เชื่อมต่อ Backend/ระบบรับคำขอ และปรับนโยบายความเป็นส่วนตัวให้ตรงกับระบบใช้งานจริง
